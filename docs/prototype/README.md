# اجرای Prototype — TruckAccounting

این پوشه یک **Prototype تعاملی HTML** از اپلیکیشن TruckAccounting است. فقط UI و مسیر حرکت بین صفحات را نشان می‌دهد؛ به هیچ Backend یا Database واقعی وصل نیست و همهٔ داده‌ها Mock (ساختگی) و فقط در حافظهٔ مرورگر هستند. با رفرش صفحه، تغییرات از بین می‌روند.

## روش ۱ — ساده‌ترین راه (بدون نصب چیزی)

1. وارد پوشهٔ `prototype` شوید.
2. روی فایل `index.html` دوبار کلیک کنید — در مرورگر پیش‌فرض (Chrome، Edge، Firefox) باز می‌شود.

همین کافی است؛ نیازی به سرور یا اینترنت نیست (فقط برای بارگذاری فونت Vazirmatn از Google Fonts به اینترنت نیاز دارد؛ در صورت نبود اینترنت هم برنامه با فونت پیش‌فرض سیستم به‌درستی کار می‌کند).

## روش ۲ — با VS Code و افزونهٔ Live Server (پیشنهادی برای توسعه)

1. پوشهٔ پروژه را در VS Code باز کنید.
2. اگر افزونهٔ **Live Server** (ناشر: Ritwick Dey) نصب نیست، از بخش Extensions آن را نصب کنید.
3. روی فایل `prototype/index.html` کلیک راست کنید.
4. گزینهٔ **Open with Live Server** را انتخاب کنید.
5. مرورگر به‌صورت خودکار روی آدرسی شبیه `http://127.0.0.1:5500/docs/prototype/index.html` باز می‌شود.
6. هر تغییری که در `index.html` بدهید، صفحه به‌صورت خودکار Refresh می‌شود (Hot Reload).

## روش ۳ — سرور محلی ساده (اختیاری)

اگر Python نصب دارید:

```bash
cd docs/prototype
python3 -m http.server 8000
```

سپس در مرورگر به آدرس `http://localhost:8000` بروید.

## مسیرهای اصلی برای تست

- **صفحهٔ اول (Splash)** → به‌صورت خودکار بعد از ۲ ثانیه به «انتخاب نقش» می‌رود (یا با ضربه/کلیک).
- **مسیر صاحب کامیون:** انتخاب نقش → صاحب کامیون → ورود → داشبورد → کامیون‌ها → افزودن کامیون → رانندگان → افزودن راننده (دعوت).
- **مسیر راننده:** انتخاب نقش → راننده → ورود → داشبورد → ثبت سفر → سفرها → ثبت هزینه → هزینه‌ها → تسویه حساب.
- دکمهٔ فلش بازگشت (بالا-راست هر صفحه) و منوی پایین صفحه (Bottom Navigation) کاملاً کار می‌کنند.
- فرم‌ها (افزودن کامیون، دعوت راننده، ثبت سفر، ثبت هزینه) داده را واقعاً به لیست‌های داخل همان Session اضافه می‌کنند و در داشبورد/گزارش‌ها منعکس می‌شوند (چون Mock Data هستند، نه چون به سروری وصل شده‌اند).

## نکات مهم

- این HTML **جایگزین اپلیکیشن Android نیست** و قرار نیست باشد؛ فقط برای تأیید UI/UX و Flow قبل از شروع پیاده‌سازی واقعی Android است.
- هیچ داده‌ای در جایی ذخیرهٔ دائمی نمی‌شود.
- طراحی به‌صورت Mobile-first و RTL و با فونت Vazirmatn ساخته شده تا حس نزدیکی به یک اپلیکیشن Android واقعی داشته باشد (قاب دستگاه، نوار وضعیت، منوی پایین).
